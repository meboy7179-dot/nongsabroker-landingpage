# 🔄 농인중개사 사용자 시나리오

본 문서는 **사용자 페르소나 정의 문서**와 지금까지의 서비스 기획 대화를 기반으로, 농인중개사 서비스가 실제 현장에서 어떻게 사용되는지를 **이야기 흐름(Scenario)** 형태로 정리한 문서이다.

---

## 시나리오 1. 외국인 근로자 – “오늘 얼마 버는지가 먼저 보인다”

### 상황
외국인 유학생 A는 내일 수업이 없어 하루 일할 수 있는 일을 찾고 있다. 한국어가 서툴러 카카오톡 공지를 이해하는 데 어려움이 있었다.

### 흐름
1. 앱 설치 후 실행
2. 국가/언어 선택 (예: 🇻🇳 베트남어)
3. 홈 화면 진입
4. **홈 상단에 ‘오늘 예상 임금 90,000원~110,000원’ 표시**
5. 금액을 보고 관심을 갖고 일자리 리스트 확인
6. 일자리 상세 진입 → 임금·시간·위치·준비물 확인(모국어)
7. 작업 수락

### 결과
- 숫자(임금) 중심 정보로 즉각 이해
- 언어 부담 없이 일 결정 가능

---

## 시나리오 2. 외국인 근로자 – “출근 기준을 정확히 안다”

### 상황
근로자 B는 과거 지각으로 다음 일을 받지 못한 경험이 있었지만, 이유를 정확히 몰랐다.

### 흐름
1. 출근 1시간 전 푸시 알림 수신(모국어)
2. 집합 장소 도착
3. 앱에서 **체크인 버튼 클릭(GPS 기록)**
4. 지각 여부 즉시 안내 메시지 확인
5. 작업 시작

### 결과
- 출근 기준을 명확히 인지
- 지각·노쇼 감소

---

## 시나리오 3. 농가 – “숙련도가 없는 사람이 오면 더 힘들다”

### 상황
농가 C는 청경채 수확 작업을 진행 중이다. 해당 작업은 속도와 요령이 중요해 초보 인력이 오면 오히려 작업이 지연된다.

### 흐름
1. 인력사무실을 통해 농인중개사로 작업 요청
2. 관리자 화면에서 **청경채 수확 경험자 필터링**
3. 기존에 평가가 좋았던 인력 배정
4. 작업 당일 전원 출근
5. 별도 설명 없이 작업 진행

### 결과
- 작업 속도 유지
- 현장 관리 부담 감소
- 재요청 의사 증가

---

## 시나리오 4. 인력사무실 관리자 – “기억이 아닌 데이터로 운영한다”

### 상황
관리자 D는 하루에 여러 농가와 수십 명의 인력을 동시에 관리해야 한다.

### 흐름
1. 농가 요청을 작업으로 등록
2. 근로자 DB에서 출근률·숙련도·평가 기준 필터
3. 작업 배정
4. 당일 출근 체크 현황 실시간 확인
5. 작업 종료 후 농가 평가 입력

### 결과
- 노쇼 감소
- 문제 인력 반복 배정 방지
- 운영 효율 향상

---

## 시나리오 5. 픽업 기사 – “누구를 태워야 하는지가 명확하다”

### 상황
픽업 기사 E는 아침마다 여러 집합지를 돌며 근로자를 태운다.

### 흐름
1. 오늘 픽업 리스트 확인
2. 집합지 도착
3. 앱에서 탑승 체크
4. 미탑승 인원 자동 표시

### 결과
- 분쟁 감소
- 책임 소재 명확화
