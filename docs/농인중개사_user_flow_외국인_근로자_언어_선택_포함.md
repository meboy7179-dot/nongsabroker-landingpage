# 🔀 농인중개사 User Flow 설계

> 전제: 근로자는 외국인(유학생/단기근로자)이며, **앱 최초 실행 시 국가/언어 선택이 필수**이다. 선택한 언어는 UI·공지·알림·경고·평가에 기본 적용된다.

---

## 0. 전체 서비스 흐름 개요

```
[앱 최초 실행]
   ↓
[국가 / 언어 선택]
   ↓
[이용 안내]
   ↓
[근로자 홈]
   ↓
[일자리 확인/수락]
   ↓
[출근 체크인]
   ↓
[작업 공지(자동 번역)]
   ↓
[퇴근 체크아웃]
   ↓
[평가/이력 누적]
```

---

## 1. 근로자 User Flow (App)

### 1.1 앱 최초 실행 & 언어 선택

```
[앱 실행]
 → [환영 화면]
   → "언어를 선택하세요"
```

**지원 언어 예시**

- 🇰🇷 한국어

- 🇻🇳 Tiếng Việt

- 🇨🇳 中文

- 🇹🇭 ภาษาไทย

- 🇰🇭 ភាសាខ្មែរ

- 🇷🇺 Русский

- 국기 + 언어명 병기

- 텍스트 최소, 버튼 중심

```
[언어 선택 완료] → [확인]
```

---

### 1.2 초기 이용 가이드 (선택 언어)

- 이 앱은 일자리를 확인하는 앱입니다
- 출근은 반드시 체크인해야 합니다
- 출근 기록은 평가에 반영됩니다

> 모든 문구는 선택한 언어 기준으로 표시되며, 스킵 가능

---

### 1.3 로그인 / 본인 확인

```
[휴대폰 번호 입력]
 → [인증번호 입력]
 → [프로필 로딩]
```

- 기존 DB 존재 시: 이름/국적/언어 자동 세팅

---

## 2. 일자리 이용 Flow

> 핵심 전략: **임금(오늘 벌 수 있는 금액)을 홈 화면 최상단에 노출**하여 근로자의 즉각적인 관심과 행동을 유도한다.

### 2.1 홈 화면 (임금 중심)

```
[홈]
 ┌─────────────────────────┐
 │ 💰 오늘 예상 임금        │
 │   90,000원 ~ 110,000원  │
 │   (확정 작업 기준)      │
 └─────────────────────────┘

 - 오늘 일자리
 - 내일 일자리
 - 확정 작업
```

- 임금 영역은 **홈 진입 시 가장 먼저 보이는 영역(Above the Fold)**
- 숫자는 크게, 설명은 최소화
- 통화 단위는 현지 언어 기준 표기

> 모든 텍스트는 선택 언어 기준

---

### 2.2 일자리 상세 확인 (임금 우선 구조)

```
[일자리 선택]
 → [상세]
    - 날짜 / 시간
    - 위치(지도)
    - 임금
    - 준비물
    - 금지사항
```

- 관리자는 한국어 입력
- 근로자 앱에서는 자동 번역 제공

표시 방식:

- 선택 언어 번역(기본)
- 한국어 원문(접기)

---

### 2.3 일자리 수락/지원

```
[수락]
 → 확인 팝업
   "이 작업에 참여하시겠습니까?"
```

- 취소 정책도 선택 언어로 명확히 표시

---

## 3. 출근 Flow

### 3.1 출근 전 알림

```
[출근 1시간 전 푸시]
 - "내일 06:20 출근"
 - "장갑을 준비하세요"
```

> 근로자 선택 언어로 제공

---

### 3.2 체크인

```
[출근 체크 화면]
 → [체크인 버튼]
    - GPS 자동 기록
    - (선택) 사진 인증
```

분기 처리:

- 정상: "출근 완료"
- 지각: "지각입니다. 다음엔 더 일찍 오세요"
- 미체크인: "출근하지 않으면 불이익이 있습니다"

---

## 4. 작업 중 공지 Flow

```
[작업 공지]
 - 작업 방법
 - 주의사항
```

표현 원칙:

1. 아이콘 + 짧은 문장
2. 선택 언어 번역
3. 한국어 원문(접기)

---

## 5. 퇴근 & 평가

### 5.1 체크아웃

```
[작업 종료]
 → [퇴근 체크아웃]
```

---

### 5.2 평가 확인 (근로자)

```
[내 프로필]
 → [작업 이력]
 → [평가]
```

- 점수 대신 아이콘/문장 중심
- 동기 부여 표현 사용

---

## 6. 관리자 User Flow (변경 최소)

- 관리자 입력 언어: 한국어
- 시스템 자동 처리:
  - 근로자 언어 기준 번역
  - 다국어 알림 발송

---

## 7. 예외 상황

### 7.1 노쇼 발생

```
[노쇼 기록]
 → 근로자 알림
   "출근하지 않았습니다"
   "다음 배정이 제한될 수 있습니다"
```

> 위협 아닌 명확한 결과 전달

---

## 8. UX 핵심 원칙

- 외국인에게 한국어를 강요하지 않는다
- 기준과 결과를 **모국어로 명확히 보여준다**
- 출근은 감정이 아닌 데이터로 관리한다

---

## 9. 한 줄 요약

> **언어 선택부터 출근·평가까지, 실패하지 않는 인력 유통의 흐름**
