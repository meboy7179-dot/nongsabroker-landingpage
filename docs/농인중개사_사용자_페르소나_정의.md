# 👥 농인중개사 사용자 페르소나 정의

본 문서는 지금까지의 기획 대화, User Flow, 서비스 구조를 기반으로 **농인중개사** 서비스를 실제로 사용하는 핵심 사용자 유형을 정리한 페르소나 문서이다.

---

## Persona 1. 외국인 근로자 (Primary User)

### 기본 정보

- 유형: 외국인 유학생 / 단기 근로자
- 국적: 베트남, 중국, 태국, 캄보디아, 러시아 등
- 연령대: 19\~60세
- 한국어 수준: TOPIK 0\~2급
- 기기 환경: 안드로이드,ios 중심 모바일 사용

### 상황 & 배경

- 카카오톡 공지 위주의 일자리 안내에 익숙함
- 한국어 이해 부족으로 출근·장소·준비물 혼동 경험 다수
- 지각·노쇼의 결과를 명확히 인지하지 못함

### 주요 목표 (Goals)

- 오늘/내일 **얼마를 벌 수 있는지 빠르게 확인**
- 안정적으로 일자리를 계속 받기
- 불이익 없이 성실하게 일하기

### Pain Point

- 지각·노쇼로 인한 작업 차질

- 매번 처음 보는 인력



- 긴 한국어 공지 이해 어려움

- 임금 정보가 눈에 띄지 않음

- 평가 기준이 불분명

### 농인중개사 가치

- 최초 실행 시 언어 선택
- 홈 화면에서 임금 즉시 노출
- 출근·평가 기준을 모국어로 명확히 인지
- 성실하면 다음 일이 보장되는 구조

---

## Persona 2. 인력사무실 관리자 (Core Operator)

### 기본 정보

- 역할: 인력사무실 대표 / 실장 / 배차 담당
- 연령대: 30\~80대
- IT 숙련도: 중간 (엑셀·카톡 위주)

### 상황 & 배경

- 다수 농가와 근로자를 동시에 관리
- 출근 여부를 기억과 감각에 의존
- 노쇼·지각으로 농가 신뢰 하락 경험

### 주요 목표 (Goals)

- 노쇼 없는 하루 운영
- 일 잘하는 인력의 재사용
- 관리 업무 표준화

### Pain Point

- 반복되는 문제 인력
- 전화·메신저 기반 출근 관리
- 평가 기록의 부재

### 농인중개사 가치

- 출근·노쇼 데이터 자동 관리
- 근로자 이력·평가 누적
- 감정이 아닌 데이터 기반 운영

---

## Persona 3. 농가 / 농장주 (Customer)

### 기본 정보

- 유형: 채소·과수 농가 운영자
- 연령대: 20\~80대
- IT 숙련도: 낮음

### 상황 & 배경

- 수확철마다 극심한 인력 부족
- 인력 품질 편차에 대한 불신

### 주요 목표 (Goals)

- 약속된 인원 정확한 출근
- 말 안 해도 일 아는 인력 확보

### Pain Point

- 지각·노쇼로 인한 작업 차질
- 매번 처음 보는 인력
- **작업별 숙련도가 필요한데, 경험 없는 인력이 오면 오히려 작업 속도가 느려지고 현장 관리 부담이 커짐**
- **설명·지시·재작업에 시간이 소요되어 농사 효율이 떨어짐**

### 농인중개사 가치

- 검증된 인력 재투입
- 평가 기반 품질 관리
- 인력사무실에 대한 신뢰 회복

---

## Persona 4. 픽업 기사 (Supporting User)

### 기본 정보

- 역할: 근로자 픽업 전담 기사
- 연령대: 40\~60대

### 상황 & 배경

- 집합지·인원 혼동
- 지각 책임 전가 경험

### 주요 목표 (Goals)

- 정확한 픽업 명단 확인
- 분쟁 없는 이동

### 농인중개사 가치

- 픽업 리스트 명확화
- 탑승 체크로 책임 소재 명확

---

## 페르소나 구조 요약

| 구분      | 핵심 관심사         |
| ------- | -------------- |
| 외국인 근로자 | 임금, 언어, 출근 기준  |
| 인력사무실   | 노쇼 관리, 재사용, 효율 |
| 농가      | 신뢰, 품질, 안정성    |
| 픽업 기사   | 명확성, 책임 구분     |
